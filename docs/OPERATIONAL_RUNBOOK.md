# Операционные точки входа

Публичный репозиторий содержит офлайн-агент и отдельно запускаемую программу RU DC. Приватные программы Daktela, reboot, Cisco collectors и браузерные клиенты не включены.

| Задача | Точка входа |
|---|---|
| Офлайн-демонстрация | `python -m agent --demo` |
| Локальный случай | `python -m agent --case <private-case.json>` |
| Локальный поиск KB | `python agent_tools/kb_search.py "<query>" --db <local.db> --top 6` |
| Перевод ASA / RouterOS на RU DC | [RU_DC_MIGRATION.md](RU_DC_MIGRATION.md), `python tools/ru_dc_vpn.py --help` |
| Тесты агента | `python -m agent_tools.offline_tests` |
| Mock-тесты агента и операционной программы | `python -m agent_tools.offline_tests --operational` |

## RU DC runner

Все режимы требуют явных `--inventory`, `--output-dir`, `--trust`, `--label`. Все режимы кроме `inventory` требуют `--host`, который должен однозначно совпадать с полем `ip` XLSX. Никакого объекта или адреса по умолчанию нет.

| Режим | Назначение и дополнительный ввод |
|---|---|
| `inventory` | Локально печатает выбранные поля сетевых устройств; никаких ZIP/сети |
| `read` | Выполняет переданные `--command` (можно повторять); оператор выбирает команды чтения |
| `file` | Последовательно выполняет проверенный `--path`, останавливаясь на распознанной ошибке CLI |
| `backup` | Создаёт RouterOS export на устройстве и скачивает `.rsc` по SFTP |
| `upload` / `download` | Передаёт файл `--path` по SFTP |
| `upload-ca` | Передаёт явно выбранный публичный `--ca`; не импортирует и не меняет trust автоматически |
| `peer-certificate` | Читает уже существующий ограниченный журнал, извлекает публичные CERT payload; требует `--log-prefix`, `--expected-peer-cn`, `--ca` |

Это существующий привилегированный операционный runner с явными входами; он не является command allowlist или исполнителем офлайн API. До `file` проверьте identity/model/firmware и точные команды. Ключи SSH обрабатывает существующий транспорт без новых механизмов в этом релизе.

## Аутентификация и скрытый ввод

По умолчанию локальный XNet → RADIUS только при отказе аутентификации. `config/network_diagnostics.json` хранит ссылки на Credential Manager/environment, не пароли. Для явно разрешённого входа пользовательской учёткой: `--username <account> --prompt-password --user-first`. Дополнительные recovery-флаги доступны в `--help`.

При автоматизированном Windows PTY используйте `--prompt-input-encoding hex` для password/SCEP challenge; hex передаётся только в скрытый stdin. Ошибка транспорта ввода останавливает вход. В обычном терминале человек оставляет `plain` по умолчанию. SCEP challenge в файле команд заменяется маркером `{{SCEP_CHALLENGE}}` и подставляется только в памяти с `--prompt-scep-challenge`.

## Неизвестный результат

Один этап — один уникальный label и запись в едином журнале операции. Программа не гарантирует идемпотентность произвольного файла команд. При timeout/разрыве SSH сначала читайте состояние; повторная отправка может повторить уже выполненное изменение. Не перезаписывайте журнал предыдущего этапа. Логи и конфиги сохраняются локально и требуют проверки перед любой передачей.
