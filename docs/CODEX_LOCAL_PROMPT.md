# Начать работу с Codex

Откройте **скачанный репозиторий** в Codex после установки зависимостей по README. Код агента уже включён; заново создавать интеграцию не требуется.

## Офлайн-анализ

> Используй mikenopa-network и network-diagnostics. Прочитай AGENTS.md и docs/AGENT_STATUS.md. Запусти python -m agent --demo и офлайн-тесты. Объясни путь проверок, происхождение evidence и неизвестные результаты. Не выполняй сетевые запросы, изменения оборудования или закрытие тикетов. Если нужна KB, используй только явно указанный локальный корпус; не подменяй отсутствующую БД.

## Перевод на RU DC

> Используй docs/RU_DC_MIGRATION.md. Подготовь перевод выбранного объекта на RU DC существующей программой tools/ru_dc_vpn.py. Точный site, inventory, приватный каталог операции, существующий trust и одобренные параметры RU DC я предоставлю локально. Начни с последнего статуса и безопасной проверки цели/модели/версии. Не повторяй уже выполненные этапы или действие с неизвестным результатом. Подготовь точные команды каждого этапа, ожидаемый результат, rollback и критерии приёмки management/VPN/portal. Выполняй только разрешённый объём; новые проверки ключей не добавляй. Операционную программу не подключай к typed API офлайн-агента.

Доступы и challenge передаются только через штатные защищённые источники или скрытые prompts. В текст запроса их не включайте. План конкретного объекта и результаты остаются в приватном каталоге, вне Git.
